# Data Terminal Design System

A cyberpunk terminal aesthetic design system built with React, TypeScript, and Tailwind CSS 4.

## Documentation

| Document | Purpose |
|----------|---------|
| `CLAUDE.md` | Agent entry point — project overview, commands, component inventory |
| `docs/DESIGN-SYSTEM.md` | Full API reference — props, usage examples, composition patterns |
| `docs/ARCHITECTURE.md` | Technical patterns — theme system, component rules, recipes |
| `docs/DECISIONS.md` | Decision log with rationale |

## Commands

```bash
pnpm dev        # Dev server (Turbopack)
pnpm build      # Production build
pnpm typecheck  # Type check
pnpm lint       # Lint with oxlint
```
